# Combustion & systems

[Back to start](../README.md)

**Lead role:** Combustion & Systems lead. Begin with a five-minute explanation of this team's function, then one worked example. Give each person their code from the private roster. Review findings before assigning follow-on work.

| Card | First-meeting output |
|---|---|
| [C1](C1-combustor.md) | Build a shared station-information sheet |
| [C2](C2-fabrication.md) | Find out what the shop can actually do |
| [C3](C3-fuel.md) | Draw the fuel-system blocks |
| [C4](C4-controls.md) | Describe controller states on paper |
| [C5](C5-model-interface.md) | Agree the model-to-controller interface |
| [C6](C6-instrumentation.md) | Compare three measurement needs |
| [C7](C7-start-options.md) | Compare starting methods as a desk study |

C1/T2 share the pressure-budget boundary. C4/C5 share the signal interface. Avoid parallel redesign of the same system; newcomers first gather inputs.

Each card includes its own Findings section. Keep notes there until they need a separate analysis artifact; add a linked subfolder only when there is actual work to store. Do not create a folder per person or duplicate CAD files. For a shared value use the [interface register](../coordination/interfaces.md).
