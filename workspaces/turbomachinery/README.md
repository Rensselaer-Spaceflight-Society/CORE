# Turbomachinery

[Back to start](../README.md)

**Lead role:** Turbomachinery lead. Begin with a five-minute explanation of this team's function, then one worked example. Give each person their code from the private roster. Review findings before assigning follow-on work.

| Card | First-meeting output |
|---|---|
| [T1](T1-compressor.md) | Find the exact compressor and its map |
| [T2](T2-diffuser.md) | Sketch the diffuser-to-combustor air path |
| [T3](T3-turbine.md) | Learn one turbine velocity triangle |
| [T4](T4-assembly.md) | Inventory existing CAD without redrawing it |
| [T5 / SAFE1](T5-rotor-energy.md) | Understand rotor energy and its unknowns |

T4 coordinates CAD with Structures. T5/SAFE1 is one task with Safety review. Map and mean-line decisions remain with the lead.

Each card includes its own Findings section. Keep notes there until they need a separate analysis artifact; add a linked subfolder only when there is actual work to store. Do not create a folder per person or duplicate CAD files. For a shared value use the [interface register](../coordination/interfaces.md).
